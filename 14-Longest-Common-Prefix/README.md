# 14. Самый длинный общий префикс (Longest Common Prefix)

**Уровень сложности:** Легкий (Easy)  
**Ссылка на задачу:** [https://leetcode.com/problems/longest-common-prefix/])

##  Условие задачи
Напишите функцию для поиска самой длинной строки общего префикса среди массива строк. Если общего префикса нет, вернуть пустую строку `""`.

### Пример:
* **Входные данные:** `strs = ["flower","flow","flight"]`
* **Выходные данные:** `"fl"`

---

##  Варианты решения

В файле `solution.py` представлена оптимизированная олимпиадная версия решения.

### Оптимальный подход: Лексикографическая сортировка
Вместо посимвольного перебора всех строк массива (горизонтальное/вертикальное сканирование), алгоритм сначала сортирует массив строк. 

* **Логика:** После сортировки по алфавиту достаточно сравнить только **первую** и **последнюю** строки массива. Если символ совпадает у них, он гарантированно совпадает у всех промежуточных строк.
* **Временная сложность:** \(O(N \log N \cdot M)\), где \(N\) — количество строк, \(M\) — максимальная длина строки (определяется стоимостью встроенной сортировки Timsort в Python).
* **Пространственная сложность:** \(O(1)\) — не требует выделения дополнительной памяти.
